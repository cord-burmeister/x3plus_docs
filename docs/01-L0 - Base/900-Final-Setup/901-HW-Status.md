# Status HW Components

## Component Versions

* Jetpack 6.2.1

## Check Jetpack

Check Jetpack via /etc/nv_tegra_release
Run:

``` bash
cat /etc/nv_tegra_release
```

This gives you the L4T version, which maps to a JetPack version. For example:

``` Code
# R35 (release), REVISION: 3.1
```

You can then look up which JetPack version corresponds to that L4T release on [NVIDIA's JetPack archive](https://developer.nvidia.com/embedded/jetpack-archive).
